# Vocabulary: statistics

Machine learning and computer science terms that drift into statistical prose, and the field term to use instead.
A starting list.
Extend it per paper.

| Outside term | Field term | Note |
|---|---|---|
| loss function | objective function; risk | |
| hyperparameter | tuning parameter | |
| training set | sample; data | |
| test set | held-out sample; validation sample | |
| learn | estimate; fit | |
| model performance | estimator accuracy; bias; variance; mean squared error | pick the one meant |
| ground truth | true value; population parameter | |
| feature | covariate; predictor; regressor | |
| label | response; outcome | |
| noise | error term; measurement error | "noise" is fine for a physical noise source |
| converge (of an estimator) | consistent | algorithmic convergence keeps "converge" |
| bin | class; interval | |
| weight (of a model) | coefficient; parameter | |
| epoch; iteration | step; iteration of the solver | |
| regularize | penalize; shrink | |
| inference (of a network) | prediction; evaluation | "inference" is reserved for statistical inference |
