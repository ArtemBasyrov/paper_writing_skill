# Vocabulary: astrophysics

Terms from software engineering and machine learning that drift into astrophysics prose, and the field term to use instead.
A starting list.
Extend it per paper.

| Outside term | Field term | Note |
|---|---|---|
| pipeline (for a method) | procedure; estimator; analysis | "pipeline" is fine for the software chain itself |
| ground truth | input model; true sky; injected signal | say which one |
| noise floor | noise level; sensitivity | |
| resolution (of an array) | number of pixels; nside; pixel size | "resolution" alone is reserved for angular resolution |
| feature | property; component; structure | |
| run (noun) | simulation; observation; realization | say which one |
| output | map; spectrum; estimate | name the object |
| hyperparameter | tuning parameter; model parameter | |
| overfit | fit the noise | |
| performance | accuracy; bias; variance; runtime | pick the one meant |
| benchmark | reference case; comparison | |
| default | fiducial | |
| sanity check | consistency check; null test | |
| edge case | limiting case | |
| iterate | repeat; solve iteratively | "iterate" is fine for an iterative solver |
| sample (of data points) | data; measurement; time sample | "sample" is reserved for a time sample or a statistical sample |
